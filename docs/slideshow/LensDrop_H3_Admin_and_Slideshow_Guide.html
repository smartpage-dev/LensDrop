01 / Admin Page 喺邊？

部署成功後，開啟你的 LensDrop 網址加 /admin（首頁 / 亦可），輸入你自己設定的 LENSDROP_ADMIN_KEY 連接。這個是 LensDrop 管理頁，不是 Hostinger hPanel。現階段未有多管理員帳戶及分角色權限。

功能可以做什麼
活動管理建立、選擇活動；建立時選擇 Review / Live 收相政策。
攝影師及裝置建立獨立上傳 Token、撤銷裝置，查看上傳及積壓狀態。
照片審核分頁查看、管理員預覽、Review / Live / Hidden；測試相不能公開。
對數及診斷已接收、雲端已驗證、客人可見計數；對數及過濾後診斷匯出。
H3 新功能投影設定、共用 Logo / 名稱、投影及客人相簿連結、QR PNG / SVG。

此指南是 H3 補充文件。完整套件保留原有使用、Hostinger 及 H2 指南；投影及 H3 升級以本文件為準。

SETUP / ADMIN COMPUTER

02 / 建立投影頁及活動品牌

1. 選擇活動。連接 Admin，選擇活動，找到 Slideshow & event branding。新活動及舊版升級後的活動，投影連結預設都是關閉。

2. 設定活動名稱及 Logo。上傳 PNG / JPEG / WebP，每檔最大 2 MiB，不支援 SVG 或動畫。伺服器重新編碼為 PNG、最大 1200 × 600，不放大小圖。Logo 可選深色、淺色或透明底；客人相簿共用同一名稱、Logo 及 Logo 底色。

3. 開啟連結及儲存。勾選 Enable slideshow，選擇效果後按 Save presentation。上傳 / 移除 Logo 會立即儲存 Logo，但不會順便儲存其他未儲存欄位。

設定選項及預設
播放效果Fade 淡入淡出（預設）、Gentle zoom 柔和縮放、Slide 左右滑動。
照片大小Contain：預設完整不裁邊。Cover：填滿畫面，但可能裁走人面或邊緣。
時間每張 3-30 秒，預設 8 秒；每 5 / 10 / 15 秒檢查公開清單，預設 10 秒。
播放範圍最近 50 / 100 / 200 / 500 張已公開相，預設 200。範圍內可最新優先、較早優先或隨機。
品牌及背景四個角位；Logo + 名稱、單獨 Logo、單獨名稱或隱藏。畫面底色可選黑、深灰、白。
建議第一次用 Fade + Contain + 8 秒 + 10 秒更新。直相會保留兩邊留白，這是保留完整構圖，不是錯誤。

次序以上傳入庫排序，不是 EXIF 拍攝時間。最近 N 張範圍以外的相不會在投影頁循環，但仍保留於相簿。

ON SITE / PROJECTOR COMPUTER

03 / 第二部電腦開啟即可播放

複製 Admin 內的 Slideshow link，在投影電腦瀏覽器開啟。不需 ADMIN_KEY，不需安裝上傳工具。先將瀏覽器移到投影螢幕，再按 Fullscreen。

上圖是 H3 實際介面的測試瀏覽器截圖，使用合成測試圖及測試 Logo；並非現場活動或實體投影驗證。圖中 QR 只是本地測試連結。

兩種 QR不要混淆用途
Slideshow QR開啟投影頁，供操作人員或第二部裝置使用。Admin 可下載 PNG / SVG。
Guest gallery QR開啟客人相簿。可選擇在投影畫面角位顯示，供現場客人掃碼睇相。

現場控制：滑鼠移動可顯示控制列；空白鍵暫停 / 繼續，左右方向鍵轉相，F 切換全螢幕。投影頁選擇樣式只影響該部電腦；選 Follow admin 即跟隨管理端。暫停不會停止可見性檢查。

投影電腦要有網絡及電源。請人手關閉睡眠、螢幕保護及系統通知。瀏覽器全螢幕需要按鍵授權；自動保持亮屏只屬盡力嘗試，不保證可覆蓋系統設定。
VISIBILITY / RECOVERY / LIMITS

04 / 公開規則及現場處理

只播放 Live，不播放 Review / Hidden / Test。活動如果是先審後出，新相要經 Admin 公開才會出現。新相在下次成功檢查後加入播放排程，不會每次更新都打斷正在播放的相。

情況處理方法
投影沒有相先確認選對活動、已開啟連結、有 Live 非測試照片，並確認投影頁沒有暫停。
需要撤回相Admin 設 Hidden；投影頁在下次成功檢查時移除，即使當時暫停亦會移除。不是即時 push。
斷線自動重試；距上次核實清單超過 30 秒，清走相、Logo 及 QR，等待連線恢復。不提供離線全相簿播放。
連結外洩關閉 Enable 或 Replace slideshow link，儲存後使用新連結及 QR。原投影頁於下次檢查停止。客人相簿連結不會改變。
Logo 不清楚白色 Logo 用深色底，深色 Logo 用淺色底。上傳後再按 Save 儲存底色選擇。

資源及私隱邊界

投影使用長邊最大 2560 px 的交付 JPEG，不載入相機原檔；畫面只維持兩個圖片圖層，不預載全部相簿。這不是原生 4K 交付保證。

投影及客人連結都是持有連結即可讀取的分享權限，不是私人帳號登入。本版未有 PIN、網域白名單或到期時間。已經被截圖或下載的副本無法遠端撤回。

未加入：只在投影排除某張公開相的獨立清單、音樂 / 影片播放、遠端控制所有投影頁暫停、相機 SDK 直連。不應把這些當成 H3 已有功能。

UPGRADE / EVIDENCE / RELEASE GATES

05 / H2 升級 H3

1. 停止及備份。暫停上傳、停止舊伺服器，備份整個持久資料目錄及秘密設定。不要只在運行中複製單一 SQLite 檔案。

2. 部署正確 ZIP。使用完整套件 deploy/ 內的 H3 Cloud ZIP，不要上傳外層完整專案。用 Node.js Web App，不是普通靜態網站。

3. 保留資料設定。沿用 LENSDROP_DATA_DIR、LENSDROP_STORAGE_ID、LENSDROP_ADMIN_KEY；升級時 LENSDROP_INITIALIZE_STORAGE=0。持久資料夾必須在部署目錄之外，且只有一個活躍伺服器程序。實際主機路徑及重部署持久性仍需驗證。

部署欄位本套件設定
RuntimeNode 22.x（至少 22.13；本次測試 22.16.0）
Root / output. / .
Entry / commandsserver.js / npm run build / npm start
資料庫會自動升級至 schema 3。要退回 H2，需要 H2 程式 + 升級前整套資料備份，不能只換舊程式。備份後的新上傳不在舊備份內；必須保留來源檔及安排重新核對。
