LensDrop H5.2 - Start here

Mitsubishi CP9550DW default photo-printer setup

Use this update in the main LensDrop repository, not Printer Lab. Both Android and Windows source change; native compilation and real printer validation are required. No APK/EXE or vendor driver is bundled. Existing H5 cloud/deployment files remain unchanged.

Open the setup guide | Read the release and test report

What you receive

Three printer profiles: a normal 4x6 photo; two identical 2x6 strips with the driver's verified multi-cut settings; and an explicit manual-cut sheet. The model's multi-cut feature is documented, but this exact Windows driver/printer combination is not yet tested. One pair-profile copy produces two strips.

Update sequence

  1. Merge the patch into the H5.1 repository, or copy the complete project contents, including .github. Preserve .git and the existing signing secret.
  2. Commit/push. Start new runs of LensDrop Android APK and LensDrop Windows Print Station on that commit.
  3. Verify Android 0.2.0-alpha.6-h5.2 / code 7, Windows 0.1.1-alpha.h5.2. Keep artifact files together.
  4. Back up the stopped station data folder and preserve phone data. Update both clients; leave station paused in simulation.
  5. Configure the official driver and capture each approved 4x6 / auto / manual preset separately. Existing profiles and jobs are not automatically reassigned.
  6. Sync station configuration, refresh phone permissions, and test simulation before a single physical photo or strip pair.

Important boundaries

Windows 11 is not listed as supported by the manufacturer's driver table. The EMEA media notice announces May 2027 end of sales for CK9046 and other 9000-series kits. Confirm local driver/media support before relying on the printer at events. Full references and calibration steps are in the setup guide.

No cloud redeployment is required for an already-H5 server. Do not initialize cloud storage or upload the full repository to Hostinger. The deploy/ ZIP remains the older unchanged H5 cloud release. Historical H4/H5/H5.1 guides and manifests are retained as history; this H5.2 guide and H5_2_MANIFEST_SHA256.txt describe the new snapshot.
