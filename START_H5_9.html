LUCE STUDIO / LENSDROP H5.9 / ENGINEERING PILOT

Event 管理、獨立 Slideshow 權限、Android 投影 QR

本次更新基於 H5.8 完整來源碼。Cloud 需要部署新版本；Android 需要 GitHub 新 APK。Windows Print Station 程式保持不變。

1. 新流程 · 2. Event 生命週期 · 3. Slideshow · 4. Android · 5. 部署 · 6. 驗收

1. 新相片公開結構

Cloud stored 不等於 Public Gallery，亦不等於 Slideshow。Guest Personal QR 仍然由獨立個人領相授權控制。每張非測試照片新增獨立 projector_visible 欄位。

設定用途
Review私人雲端相片庫；預設不在全場 Gallery。
Public Gallery / live全場公開相簿；不會因為改成 live 而自動批准投影。
Projector visible獨立投影權限；即使照片仍為 review，亦可由 Admin 明確批准投影。
Auto projector for FUTURE photos預設 OFF。Admin 明確開啟後，未來符合條件的新照片可自動加入公開投影，不會因此加入 Public Gallery。
私隱提醒：投影頁面係公開可分享連結。即使照片仍為 Review，只要允許 Projector visible，持有投影連結的人便可觀看。不要在私人婚禮活動無意開啟自動投影。

2. Event 管理

Cloud Admin → 01 Overview → 選 Event → Close / Archive / Unarchive。變更前需要輸入 Event 名稱。狀態流程：

Active → Closed → Archived
           ↑         |
           └─────────┘
Closed → Active（重新開放）

Closed：拒絕新相片上傳 session、新手機配對邀請及新 Staff Photo Desk print orders；原有已開始的上傳及打印工作需要另外核對，已發出的 guest/slideshow link 不會自動撤銷。Archived：額外要求所有未決打印工作先核對，並保留所有媒體、連結及紀錄。既有離線 LAN 授權可能在有效期內仍可使用；封存不等於遠端取消已接受工作。

Delete EMPTY Archived Event 只接受已封存且完全沒有照片、上傳、裝置、配對、領相、Print Station／Print Job 及 Logo 嘅空 Event；需要同時輸入完整 Event 名稱與 ID。有資料嘅 Event 不會永久刪除。

3. Cloud Slideshow & Branding

  1. 01 Overview 選擇 Event；確認 Event 名稱及狀態。
  2. 03 Photos & Guests：按張選 Show on slideshow 或 Remove from slideshow；Public Gallery live/review/hidden 繼續獨立控制。
  3. 05 Slideshow：Enable slideshow，設定 Logo、名稱、Style、Fit、Interval、Polling、Order。
  4. 如活動需要即時投影所有新相，明確開啟 Auto projector for FUTURE photos，並注意私隱。
  5. 複製該 Event 嘅 /s/<token> Slideshow Link 到投影電腦。每個 Event 有自己獨立 token。

Slideshow 同 Public Gallery 仍然使用相同 Event Name/Logo，但照片顯示資格分開。Cloud Admin 會顯示 Cloud stored、Review、Public Gallery、Projector Eligible 數量；投影頁本身會按原有 5／10／15 秒輪詢。

4. Android Slideshow QR

Android LensDrop → Support → Show / open / print event slideshow QR。手機必須已配對該 Event、可連 Hostinger，而且 Admin 已啟用 Slideshow。

  1. 按 Refresh：用本機已配對攝影師 credential 查詢 /v1/device/slideshow，不需要 Admin Key。
  2. Show QR larger：向客人顯示投影連結 QR；Open slideshow page：在瀏覽器打開。
  3. Print ONE event slideshow ticket：使用自己已配對嘅 58B3，打印前重新向 Cloud 核實連結仍然啟用且未輪換，手動確認後只送一次。
  4. Slideshow ticket 與 Guest Collection Ticket 標題不同，絕不建立 CP9550DW 相片打印工作。

Bluetooth 傳送成功只代表 bytes sent；實際出紙及掃碼要另外確認。打印失敗／未知結果不會自動重印。離開畫面會中止其 Bluetooth 操作，但不停止照片上傳。

5. GitHub / Hostinger 升級次序

  1. 只用 H5.8 完整來源碼作基準合併 H5.9 Patch；或者使用 H5.9 完整包。勿將 Patch 套落不明混合版本。
  2. Commit/Push，跑新 LensDrop Android APK workflow，保留原有 signing secret；必須通過來源完整性、測試、assembleDebug 及 lintDebug。
  3. 停止 Cloud／Windows，核對未知打印結果，備份完整 Cloud data directory（含 SQLite/WAL、照片、私鑰、Storage ID）及 Windows ledger。保留 Android 本機資料。
  4. Hostinger Node Web App 部署 LensDrop_Hostinger_Cloud_H5_9_EventSlideshow.zip；保持原本 Admin Key、DATA_DIR、STORAGE_ID，LENSDROP_INITIALIZE_STORAGE=0。
  5. 確認 Cloud /health H5.9、schema 8、舊 Event／相片／Guest QR／Print Station 仍存在。再安裝同簽署身份嘅 Android H5.9 code15。
Cloud schema 8、Android QueueDb schema 8 均為資料遷移。不可只將舊 Cloud ZIP 或舊 APK 蓋返落去當 rollback。 回退需要完整相容資料備份及打印核對；先喺 disposable Test Event 測試。

6. 驗收次序

  1. 舊 live 照片升級後仍可投影；舊 QR token 不變。
  2. 新 private Review 照片預設不公開；按 Show on slideshow 後只在投影顯示，Public Gallery 不變。
  3. 開啟 Auto projector 後上傳新相，只有投影自動增加；關閉後再上傳新相不增加。
  4. Event A／B 隔離；旋轉 Event A token 後舊連結失效，Event B 不受影響。
  5. Android Support 顯示正確 Event 嘅 Slideshow QR，能放大／開啟；未啟用時拒絕印票。
  6. 58B3 真機打印後掃完整 URL；打印前轉換／停用 Slideshow link，應拒絕舊票。
  7. Close / Archive 不刪媒體；有未決打印時拒絕 Archive；空 Event Delete 有雙重確認。
  8. Guest Group QR、Watch Folder、LAN/Cloud Print、CP9550DW 4×6／2×6 功能回歸。

驗證邊界：本地 Cloud/API／SQLite 測試與 Java 封包測試並非 Android 真機／Hostinger 實際部署／58B3 紙張或 CP9550DW 實機驗證。
