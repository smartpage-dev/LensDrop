QUICK START

The recommended event sequence

1 · Cloud eventConnect with the existing private Admin Key, then choose or create the event in Overview / Setup.
2 · Staff pairingSetup & pairing → Create 5-minute pairing QR. Approve using the six-digit code displayed on the actual device.
3 · Station and phonesEach Android selects its own watch folder. Windows station sets LAN endpoint, stays paused and in Simulation, then captures printer profiles.
4 · RehearseConfirm private archive, group/single QR delivery, a simulated print and staff handover before physical output.

Important: “Create device token” is a legacy manual method and does not generate a pairing QR. Use the dedicated Staff QR pairing section instead. No live keys or guest images are included here.

CLOUD

Five clear workspaces

Overview shows selected event, photo counts and photographer reports. Setup & pairing contains event creation, five-minute staff QR and station permissions. Photos & guests contains private/public review and personal delivery. Staff printing provides ticket lookup and explicit staff ordering. Slideshow contains branding and projector links.

WINDOWS STATION

Pair → configure → simulate → operate

Overview summarizes status. Setup & pairing claims station invitation, shows the device approval code and saves LAN/simulation settings. Printer profiles captures actual CP9550DW driver settings. Print queue shows jobs and unknown outcomes. Staff Photo Desk supports authorized lookup, photo selection and manual print confirmation.

LIVE STATUS

Traffic lights and refresh intervals

GreenRecent successful API/heartbeat report, or queue enabled. It does not prove the camera is connected or paper was printed.
AmberSome devices stale, station paused, simulation, or physical output requires operator verification.
RedAPI failure, revoked station, or no recent device heartbeat. “Stale” is not absolute proof a device is offline.
GreyNot connected, no event/device, or status unknown.

Cloud auto refresh: 15s / 30s / Off. Windows status: 5s / 15s / Off. Hidden browser tabs pause polling; routine status checks do not reset unsaved event/slideshow/print forms. The Staff Photo Desk still uses explicit refresh while an order is being prepared.

INSTALLATION & SAFETY

What actually needs upgrading

Cloud: deploy the H5.7 root-ready cloud ZIP after a consistent stopped-data backup. Preserve your existing Admin Key, Storage ID, data directory and LENSDROP_INITIALIZE_STORAGE=0. The database schema stays 7.

Windows: rebuild the Windows Print Station workflow from the updated GitHub commit, then replace the stopped portable application while preserving its complete data folder and driver profiles. Start paused/in Simulation.

Android: no code changes in this increment; continue H5.6.1 with the existing signing key and queues. Do not uninstall to resolve a signature mismatch.

This is a source/UI pilot. Browser mockups and local tests do not prove a Hostinger redeployment, native Windows build, CP9550DW cut or eight-hour event reliability.
