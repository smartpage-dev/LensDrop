Connecting

01 · Pair with your event

In cloud Admin, create a Windows Print Station invitation. Paste its full link below.

Open shared web Admin

Admin credentials are entered on the cloud page only. This local dashboard uses a separate per-run authorization.

02 · Local network & safety

Phone TLS endpoint uses port 54173. Keep the same address with a router DHCP reservation. Guest Wi-Fi isolation must be off.

A station setting does not change Windows sleep settings. Keep this user signed in and the PC awake.

Pair another photographer

Scan with Android Staff Setup. Compare the code and approve in web Admin. Initial enrollment needs internet.

03 · Validated printer profile

H5 provides a single full-photo Contain profile. Borderless/cutter support depends on the Windows driver and must be physically tested.

04 · Print queue

Simulation results are explicitly labelled. Driver submission is not proof of physical output.

Job identities are retained for duplicate prevention. Cancelling here does not undo a photo already submitted to Windows.
